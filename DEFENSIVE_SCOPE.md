# Authorized defensive scope

Review explicitly supplied, authorized local Go source files. Results are
bounded declarations of selected source-policy conditions and unknowns.
They do not prove exploitation, vulnerability reachability, build success,
certificate authenticity, entropy quality or applicant eligibility.

Frozen families: TLS builtin verification and declared minimum protocol;
RSA requested constant key bits; version-aware supported random readers in
cryptographic API arguments; straight-line weak bytes into AES key material.
The README defines all supported syntax and conservative unknown boundaries.
Ordinary simulation random calls produce observations `OPEN`, without a risk
finding. No source names/comments are accepted as security-purpose evidence.

No module loading/resolution/downloading, SSA, subprocess, external repair
service, API query, workflow trigger, target build/execution, TLS handshake,
key generation, credential probe, file modification or installation of
reviewed code exists in the analyzer. Engineering builds/installations are
for this new analyzer and its single pinned Unix library only.

Status: defensive topic fit conditional on this authorized local subset.
CVP eligibility remains `OPEN`: source-policy tests do not verify a person's
identity, organization, invitation channel, ownership or admission decision.
